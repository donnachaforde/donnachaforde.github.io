# Dunner's Guide to Agile Scrum Project Mangement Conventions (using Jira)
TL;DR

I also like having a 'single source of truth' and think it critical to maintain this and avoid other priority lists in other mediums. The following are the practices conventions I apply to my engineering projects and Jira projects in order to ensure that we maintain that single source of truth - and - automate status reporting as far as possible.
